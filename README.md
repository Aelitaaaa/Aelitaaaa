## About Me

Hi, I'm **Muhamad Dzaky Putra Fardian**, an Informatics student at **Gunadarma University** based in Indonesia.

I'm interested in building software that is useful, clean, and enjoyable to use. Most of my time is currently spent exploring **Full Stack Web Development**, **Mobile Development**, and **Developer Tools** while turning what I learn into real projects.

I enjoy working across different parts of software development, from building interfaces and backend systems to experimenting with APIs, databases, automation, and CI/CD.

My goal is to grow into a **Full Stack Developer** who understands not only how to make an application work, but also how to structure, maintain, improve, and deploy it.
