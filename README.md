## About Me

Hi, I'm **Muhamad Dzaky Putra Fardian**, an Informatics student at **Gunadarma University** based in Indonesia.

I enjoy building software, experimenting with new technologies, and turning what I learn into real projects. My current interests include **Full Stack Web Development**, **Mobile Development**, automation, and developer tools.

I like working across different parts of development, from creating interfaces and backend systems to working with APIs, databases, CI/CD, and application architecture.

My goal is to become a **Full Stack Developer** who can build applications that are useful, maintainable, and ready to grow.
